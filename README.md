# Rock, Paper, Scissors Game 🎮

A classic implementation of the fun Rock, Paper, Scissors game built using Python and Jupyter Notebook. Part of my personal programming portfolio and data science learning journey.

## Features ✨
* Interactive user input and game loop (`Play again [Y/N]`).
* Random computer choice generation.
* Real-time score tracking for both the player and the computer.
* Clean and structured conditional logic.
